2026-10-23 候选修复。现场164054和此前162702均在新鲜、停稳数据下，15帧
right/rear全极差轮流略超10mm，START_VERIFY_TIMEOUT。仅凭汇总值无法重建现场
每一帧或保证存在12帧稳定子集；现场修复仍待复测。

旧实现先以整批中位数剔除超过20mm/2deg的粗大联合离群帧，要求保留>=12，
随后却要求所有保留帧都满足10mm/2deg极差。新的第二步寻找同一组12帧，同时

不足12帧或只有各轴独立12帧（没有同一组12帧）仍不通过。粗大剔除与后续未参与
一致性见证的帧合计最多3/15。共同保留帧数、非有限数值规则、15帧新鲜/停稳窗口不变。

`median`与原始`spread`仍基于所有粗筛保留帧计算，绝不改成选定子集的中位数，
也不向目标值偏置。稳定性通过只允许下一次校正/最终核对，不能直接宣告P01。
最终right0.26m、rear0.28m各5mm和墙角0.5deg要求保持；所有微调、暂停、漂移、
次数和时间预算保持。逐渐变化超过限制的窗口仍可能失败；少量尾部变化能够满足12/15
是新的鲁棒一致性策略，不等于证明传感器完全没有偏移。

日志增加`consensus`与`consensus_right/rear/angle`，分别报告见证帧数与其极差。
全部保留帧均合格时见证数等于retained；否则12表示找到一个合格见证，不表示最大簇。
子集见证的极差可能随帧顺序不同，但稳定结论/原批中位数/原极差应与排列无关。
